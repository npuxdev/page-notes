# Page Notes artwork

- `page-notes-icon.png`: original square application icon, 1254 × 1254.
- `page-notes-linkedin-banner-np.png`: final LinkedIn announcement banner, 1536 × 1024 (3:2), with Nicholas Pulido's supplied NP mark and `github.com/npuxdev/page-notes`.
- `page-notes-linkedin-banner.png`: earlier banner without the creator signature.
- Browser-sized PNGs are in `../icons/` and are wired into the extension manifest.

Created with the built-in image-generation tool. Browser icon sizes are resampled from the generated master. The banner is an illustration, not a screenshot of the product.

## Prompt direction

Icon: A bold, simple mint (#9ae9c6) page-and-cursor mark on deep ink navy (#12212d), centered with generous margins, no text, designed to remain recognizable as a Chrome extension icon.

Banner: A 3:2 professional product announcement matching the icon. Exact headline “Point. Comment. Export.”; supporting text “Website feedback, ready for your AI agent.”; abstract selected webpage element and numbered comment; footer “Inspect elements • Edit copy • Capture context”.

Branding revision: Preserve the banner, reproduce the supplied white NP monogram in the upper-right corner, and add “github.com/npuxdev/page-notes” as a mint footer line. Preserve typography, spacing, palette, and 3:2 aspect ratio.
